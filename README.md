# InsureCell - Insurance Management System

InsureCell is an insurance policy and claims management system built with the MERN stack. It provides portals for customers to explore policies, purchase coverage, and file claims, alongside an administrative portal for reviewing claims and approving policy renewals.

## Setup

### Backend
1. cd backend
2. npm install
3. Configure .env with PORT, MONGO_URI, and JWT_SECRET
4. node seed.js
5. npm start

### Frontend
1. cd frontend
2. npm install
3. npm run dev
